# Golden corpus (subset of the TokenKey PoC handoff corpus)

Used by `tests/test_corpus.py` (ctest `tkhost_corpus`) to prove the device engine reproduces the
PoC reference byte for byte.

| file | content |
|---|---|
| `inputs.tar.xz` | 68 requests (`<session>/req_NNN.json`: `messages`, `next_assistant`, `t_s_modelled`, `licence`) from 4 sessions |
| `expected_digests.json` | sha256 of `json.dumps(messages, ensure_ascii=False)` of the PoC's reduced request, per variant × request (340) |
| `expected_metrics.json` | PoC recall metrics per variant (next-turn reference recall, newest-error recall) |
| `mcu_stats.json` | PoC observed maxima (segments, dupset, line/message bytes) |

The full expected outputs (≈ several MB) are not copied; set `TK_POC_CORPUS=<handoff>/corpus` to
also compare against them file by file.

## Variants checked

|---|---|---|
| `D_firmware_as_written_economy` | `d-economy` | custom: RULES V01, KEEP 25, stateless |

Note: on this subset S-protect Economy/Balanced reference recall is 99.37 % (one miss in
docker-py request 7, `setup.py`), as in `expected_metrics.json`; the ≥ 99.9 % figure is the PoC's
full 1,019-request run. Newest-error recall is 100 % for all S variants and G.
